# Report fonts

Reddit Sans and Reddit Mono (Latin subset, variable weight), the typefaces
used on rtcamp.com. Both are licensed under the SIL Open Font License 1.1:
https://openfontlicense.org — source: https://fonts.google.com/specimen/Reddit+Sans
and https://fonts.google.com/specimen/Reddit+Mono.

Loaded only on the client report view (`AMC\Reports\ClientView`).
